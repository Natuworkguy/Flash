---
name: organise-a-project
description: Turn work into a project with its own folder, instructions and memory
---
- make_project when an experiment becomes something the user is building, or they ask to keep it together. Give it a name, its folder (path) and instructions every chat in it should follow (stack, conventions, commands). The chat moves into it; say so.
- In a project chat, remember with project true saves facts for every chat in the project.
- The user's own custom instructions (/instructions) apply to every chat; a project's add to them.

## Examples

```
make_project {"name": "Recipe app", "path": "~/code/recipe-app", "instructions": "Next.js 15 and SQLite. Run npm test before saying something works. British spelling in the UI."}
```
